# 0045 — Collapse vestigial `AICommandResult` into `AIChatResult`

## Context

Feature 0044 removed the `POST /api/ai/schedules/<date>/command/` endpoint and its
`run_command` service function. That left the `AICommandResult` dataclass with **no
production producer**. It survives only as:

1. a member of a type union (`_apply_actions_sync`'s parameter annotation),
2. a test-construction vehicle (`test_ai_apply.py`),
3. two sibling docstring references (`AIChatResult`, `AIDraftResult`).

`AIChatResult` is a strict **superset** of `AICommandResult`: it has all three fields
(`raw_response_text: str`, `parsed_actions: list[dict]`, `explanation: str`) plus
`ask: str | None`. `_apply_actions_sync` reads only `result.parsed_actions` (verified:
early `if not result.parsed_actions: return` at `views.py:556`, then handed to
`plan_mutations`), so switching its parameter to `AIChatResult` alone is field-safe.

This is the deferred follow-up claude-review raised on PR #138. Backend-only
type/dead-code cleanup. **No behavior change.**

## Implementation order (TDD)

This is a pure dead-code/type cleanup, so there is no meaningful **red** phase (no new
behavior to fail-first). The discipline is instead **characterization-green → refactor**:
an **existing** test (`TestRollbackPropagation`) is switched to the new type and proven
green **first**, characterizing that `_apply_actions_sync` accepts an `AIChatResult` and
the rollback contract holds, **before** the old symbol is deleted.

### Step 1 — Switch the green-guard test to `AIChatResult` (proves the contract holds)

Edit `backend/tests/test_ai_apply.py`:
- `:8` — change import from `AICommandResult` to `AIChatResult`.
- `:26-38` — change the constructor call from `AICommandResult(...)` to
  `AIChatResult(...)`, adding `ask=None` (the one field `AIChatResult` has that
  `AICommandResult` lacks). Keep `raw_response_text`, `parsed_actions`, `explanation`
  values unchanged.

Run **just this test** and confirm GREEN:
```
uv run pytest backend/tests/test_ai_apply.py::TestRollbackPropagation -q
```
This proves `_apply_actions_sync` accepts an `AIChatResult` and the `_Rollback` /
409 stale-fingerprint contract is unchanged — **before** `AICommandResult` is deleted.
`AICommandResult` still exists at this point; the union annotation still admits both
types, so a passing run here isolates "does the new type drive the same path".

### Step 2 — Delete the dataclass + remove imports + scrub docstrings (refactor to green)

Only after Step 1 is green:

1. `backend/ai/service.py` — delete the retention comment block (`:98-101`) and the
