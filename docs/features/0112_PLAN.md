# 0112 — External calendar past-state at saved-zone midnight (issue #229)

Fixes [issue #229](https://github.com/erzhan12/day-forge/issues/229). Reviewed against current `main` (after 0111). The issue cited `main@ecf5772`; line numbers have moved.

## Problem

`ExternalEventsPanel` classified past/current/future from a computed `today` that called `todayString()` with no Vue dependency. Vue cached that civil date for the panel's lifetime. Leaving Schedule open across midnight therefore left `ee-item--past` stale until remount.

`useNowMinutes` already samples the **saved** IANA zone every 60s and exposes `todayDate` (always the current civil date) and `nowDate` (null when the viewed day is not today). After midnight on yesterday's view, `nowDate` becomes null and `nowMinutes` becomes null. If the panel still believes `today === viewedDate`, `isExternalEventPast` hits `nowMinutes === null → false` and an overnight event stays styled as current.

`nowDate` cannot be the panel's "today": it is null off-today, which would break "every event on a past day is past". The live civil date is `todayDate`.

## Current code

Schedule already passes `:today-date="todayDate"` to the center, Dark 4a fallback-center, classic sidebar, and Dark 4a rail instances. The panel prefers `props.todayDate` when present. That wiring was not locked by a midnight-crossing test, and the `todayString()` fallback still froze on first render: a `nowMinutes` tick (the original "only pass nowMinutes" integration) did not re-sample the date.

## Decision

1. Keep `todayDate` from `useNowMinutes` as the panel's live civil date. Do not pass `nowDate`.
2. Re-read `todayString(timeZone)` when `todayDate` is missing **and** `nowMinutes` changes, so a parent that only forwards the clock still rolls over. Do not add a second timer in the panel.
3. Classify with `isExternalEventPast` as today: viewed date vs that civil date, then timed end vs `nowMinutes` in the saved zone.
4. Lock the behaviour with a panel test that changes `todayDate` without remounting, a fallback test that crosses Asia/Qatar midnight without crossing UTC, and Schedule tests for center and sidebar that keep the page mounted across the same tick. Same-day `nowMinutes` updates must not regress.

No backend, API, migration, PiP, or logout-privacy change. Focus Indicator keeps the same `useNowMinutes` owner (0111 generation guard stays).
