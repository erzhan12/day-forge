# 0110 — Proportional mid-day gaps in the Dark 4a timeline

The owner asked to bring back the proportional height of free time between blocks. Feature 0106 capped every free gap in the Dark 4a stack layout at the edge-stub height (60 px at 2 px/min) so the whole day would fit the column without scrolling. That hid how much free time a day has: a 70-minute gap and a 170-minute gap both rendered as the same 60 px row.

## Why 0106 capped gaps

0106 followed the Design Mentor spec. Bug 2 in [0106_PLAN.md](0106_PLAN.md) read "a mid-day gap of 170 minutes takes 340 px", and the spec asked for a day that fits the schedule column at `scrollTop` 0. `buildTimelineStack` therefore capped gaps and spacers at `STUB_MINUTES × pxPerMinute`. The cap was intentional, not a regression.

## Decision

Only gaps between two blocks return to the true scale. Everything else from 0106 stays:

- Blocks keep the 28 px floor and the compact row below 36 px. Returning to the linear layout would clip 5-minute blocks to 10 px again.
- A gap that touches the window start or the window end stays capped at 60 px. These edge stubs existed before 0106 (feature 0017).
- An empty day is one gap touching both edges, so it stays capped.
- Today's idle stretch from the last block to "now" is still merged with the tail into one capped row. Before 0106 it grew with the clock. Keeping it merged means the column height does not change as time passes.
- Spacers (out-of-window geometry) stay capped.

The change is one condition in `buildTimelineStack` (`frontend/src/utils/timelineStack.ts`): the cap applies when the segment is a spacer, starts at `window.startMinutes` or ends at `window.endMinutes`. Hour ticks and drag need no code change. Ticks already appear inside an uncompressed gap, and drag converts pointer pixels through the same axis map. Drag inside a long gap becomes precise again: one 5-minute step is 10 px instead of about 1.8 px.

Trade-off: the day no longer fits the column. The 22 Nov 2026 fixture grows from 538 px to 898 px.

## Changes

- `frontend/src/utils/timelineStack.ts`: cap only edge gaps and spacers.
- Tests: `timelineStack.test.ts`, `timelinePresentation.test.ts`, `Timeline4a.test.ts`, `useDrag.test.ts`, `GapSlot4a.test.ts` (one rename).
- `frontend/scripts/playwright/dark4a-day-fit.mjs`: replace the "day fits at `scrollTop` 0" check with "the 12:10–15:00 gap is 340 px and the edge gaps are at most 60 px"; centre the compact row before hit-testing at 390 px, because the fixed chat dock covers the bottom of the narrow viewport.
- OpenSpec change `0110-proportional-gaps`: `frontend/schedule-page` "Dark 4a stack layout" and "Dark 4a gap row", `frontend/undo-and-drag` "Drag cancellation and frozen geometry".
- `RULES.md`: the stack-layout line.

No backend, API or migration change. Classic, Strategic and Light Premium keep the linear layout and are unaffected.
